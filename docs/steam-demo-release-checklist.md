# Steam Demo 发布清单

## 仓库内可完成

- Windows x86_64 独立构建可启动。
- 构建只描述并包含 Demo 已实现功能。
- 简体中文与英语全流程可用。
- 存档、离线结算、损坏恢复和经济边界通过测试。
- 至少 5 张截图来自真实 Demo 画面，不使用概念图冒充玩法。
- 准备简短描述、详细描述、支持语言和系统需求草案。
- 构建包不含源存档、密钥、测试产物和个人信息。

## 需要开发者 Steamworks 账户

- 支付 Steam Direct 费用并创建基础游戏 App ID。
- 从基础游戏后台创建关联 Demo App ID，应用类型设为 Demo。
- 创建 Windows depot，上传 Demo 构建并设置默认分支。
- 填写内容调查、语言、控制器/玩家模式和系统需求。
- 上传胶囊、库资产、至少 5 张 Demo 实机截图及可选预告片。
- 商店页只勾选 Demo 中真实存在的功能。
- 先提交商店页审核，再提交接近最终状态的构建审核。
- 为审核和返工至少预留 7 个工作日。
- 若在正式版之前发布 Demo，先让基础游戏商店页处于 Coming Soon。
- 发布 Demo 后重新发布基础游戏商店页，使下载按钮出现。

## 当前不应宣称

真实好友联机、公共匹配、Steam 成就、Steam Inventory、市场交易、完整改装、转生、全球排行榜、真实天气和自由聊天均不在本 Demo 中。
