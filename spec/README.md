# 《一起停车吧》规格索引

当前规格为讨论稿 `v0.1`，用于统一产品方向、MVP 范围和后续开发约束。标记为“暂定”或“待验证”的内容需要通过原型和试玩调整。

- [游戏机制规格](game-mechanics.md)：核心循环、停车收益、成长、社交、转生、排行榜和商业模式。
- [视觉规格](visual-spec.md)：视角、美术、车辆、场景、天气、窗口、动画、声音和本地化。
- [开发规范](development-standard.md)：分支、完成定义、质量门槛和发布节奏。
- [第一版验收规范](acceptance-v0.1.md)：`0.1.0-alpha` 的范围和可验证条件。
- [Steam Demo 规格](steam-demo.md)：`0.3.0-demo` 的玩家旅程、内容边界和发布验收。

## 产品一句话

《一起停车吧》是一款面向 Steam 的轻社交桌面挂机经营游戏。玩家把虚构车辆停进好友或 NPC 的停车场赚取收益，再通过买车、升级、收藏、改装和转生持续成长。

## 规格优先级

发生冲突时按以下顺序处理：

1. 当前明确的用户需求。
2. `spec/` 中标记为 MVP 的规则。
3. 本索引和远期规划。
4. 实现便利性。
